
SHALU AI — NATURAL FEMALE VOICE UPGRADE
========================================

This version is tuned toward the soft, conversational anime-assistant feel
requested from the uploaded reference video. It does NOT clone the speaker
or copy the speaker's identity.

WHAT CHANGED
------------
• Prefers Microsoft Edge online/natural female voices when available.
• Natural Female preset: slightly slower rate + gentle pitch.
• Conversational mode adds better punctuation-aware timing.
• Word-boundary events drive the VRM mouth expressions while speaking.
• Automatic blinking and gentle idle movement.
• Voice preview button for quick testing.
• No ElevenLabs account or API key is required.

BEST VOICES TO TRY
------------------
The app automatically ranks likely online/natural female voices first.
Names may vary by Windows/Edge installation. Examples can include:
Microsoft Aria Online (Natural) - en-US
Microsoft Jenny Online (Natural) - en-US
Microsoft Sonia Online (Natural) - en-GB

If an online voice is available, it is preferred because Edge documents these
online voice fonts as higher quality than pre-installed system voices.

START
-----
Double-click START_SHALU_NATURAL.bat.
Then choose a voice and press TEST VOICE or SPEAK.

NOTE
----
Voice availability is controlled by the browser/Windows speech service, so
the exact voice list can differ between PCs.
