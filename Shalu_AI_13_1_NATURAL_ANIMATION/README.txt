SHALU AI 13.0 — LOCAL NEURAL VOICE
====================================

What is new:
- Local Piper neural TTS instead of browser SpeechSynthesis.
- No ElevenLabs account or API key.
- 3D SHALU.vrm included.
- Emotion detection + VRM expressions.
- Sentence-by-sentence speaking and natural pauses.
- Gentle idle motion + blinking.
- Voice generation happens on your PC.

FIRST TIME:
1. Make sure Python is installed and "python" works in CMD.
2. Double-click SETUP_SHALU_13_NEURAL.bat.
3. Wait for Piper + the voice model to finish installing.
4. A browser window will open automatically.

NEXT TIMES:
- Double-click START_SHALU_13_NEURAL.bat.

IMPORTANT:
- First setup needs internet to install/download the voice.
- After setup, voice synthesis is local.
- The included model is not a clone of the reference video speaker.
- If your Python installation is very new and Piper installation fails,
  use a supported stable Python version and rerun setup.


13.1 ANIMATION/LIP-SYNC UPGRADE
- Live audio amplitude drives mouth opening.
- Spectrum-based mouth-shape blending (aa/ih/ou/ee/oh).
- Stronger emotion expressions during speech.
- Subtle head/neck motion while talking.
- Improved idle movement and blinking.
- This is real-time approximate lip-sync, not phoneme-perfect lip-sync.
