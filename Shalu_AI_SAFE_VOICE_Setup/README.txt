
SHALU AI - SAFE FEMALE VOICE SETUP
===================================

This version does NOT require an ElevenLabs account or API key.

It uses the browser's SpeechSynthesis voices. In Microsoft Edge, web apps can use
online text-to-speech voice fonts when they are available/enabled. These can be
higher quality than pre-installed system voices.

HOW TO START
------------
1. Keep SHALU.vrm in this folder.
2. Double-click START_SHALU_SAFE_VOICE.bat
3. Edge will open http://127.0.0.1:8765/
4. Choose a female English voice from the Voice dropdown.
5. Type text and press SPEAK.

IMPORTANT
---------
- No API key is needed.
- Do not put secret API keys in browser JavaScript.
- Voice availability depends on the voices installed/available in Edge/Windows.
- This is a safe alternative, but it may not sound as human-like as premium
  dedicated TTS services.

The 3D model, blinking, emotion expressions, and simple mouth animation are
included.
